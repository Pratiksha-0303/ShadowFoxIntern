# ShadowFox Internship Projects
This repository contains Java projects developed during the ShadowFox Internship Program.
---
# 1. Student Information System
Student Information System is a Java-based desktop application developed using Java Swing GUI. The project is designed to manage student records efficiently through a simple and user-friendly interface.
The system allows users to perform various operations such as adding student details, viewing all records, updating existing student information, searching students using roll numbers, deleting records, and clearing input fields.
The application uses ArrayList for storing student data dynamically and JTable with DefaultTableModel to display records in a tabular format. Event handling is implemented using ActionListener for button operations.
This project demonstrates the implementation of Object-Oriented Programming concepts, GUI development, data handling, and user interaction in Java.
## Technologies Used
- Java
- Swing
- JTable
- ArrayList
- Event Handling
- OOP Concepts

# 2. Simple Calculator
Simple Calculator is a menu-driven Java application developed using Core Java concepts. The project performs various mathematical and conversion operations through a command-line interface.
The calculator supports arithmetic operations such as addition, subtraction, multiplication, division, modulus, square root, and exponent calculations. It also includes temperature conversion and currency conversion features.
The application uses loops, switch-case statements, conditional statements, exception handling, and Java Math functions to perform operations efficiently.
## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Square Root
- Power Calculation
- Temperature Conversion
- Currency Conversion
- Exception Handling
## Technologies Used
- Java
- Core Java
- Scanner Class
- Exception Handling
- Switch Case
- Loops
